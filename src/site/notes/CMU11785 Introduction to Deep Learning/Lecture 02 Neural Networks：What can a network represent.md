### Last Class
神经网络是一个box，接受输入并计算输出 -- 所谓的box 就是一个functions
这些function是什么？在人类机体中，这些function是由人类大脑计算的 -- 人工神经网络模仿人类大脑的机构
人类大脑是由叫神经元的计算单元网格组成 -- 模拟神经元所建立的人工神经网络的计算单元网格的单元叫感知机。 接受一推输入（可以是实数，可以是布尔的），计算这些输入的加权和，并将这个加权和与一个阈值进行比较，如果超过阈值就会激活。即$\sum w_ix_i>T?1:0$ 
这完全可以重写成$\sum w_ix_i -T \geq 0$ 。加上一个偏移量b=-T，把$\sum w_ix_i -T$记作z，然后通过一个阈值激活函数，如果是正为1负为0
所以首先核心要计算的就是仿射函数z；然后通过一个激活函数，激活函数可以选择不同的函数。
单个感知机是不够的 -> 我们需要构造多层感知机(multi-layer perceptron)
感知机可以输入布尔值，输出布尔值 -- 表示布尔函数
感知机可以输入连续值，输出布尔值 -- 二分类问题
感知机可以输入连续值，输出连续值 -- 回归表示连续函数

### MLPs as universal Boolean functions
前面我们学过了AND, OR, NOT都可以用一个感知机实现 现在我们把AND, OR, NOT 推广到多个输入的情况，仍然只需要一个感知机，所以说感知机可以表示广义的布尔函数或者说通用布尔函数
![Pasted image 20261119185528.png\|446](/img/user/accessory/Pasted%20image%2020261119185528.png)

### A discussion of sufficient depth and width
前面提到了 具有单个隐藏层的MLPs是一个通用布尔函数，是一个通用分类器，也是一个通用函数逼近器。但在通用分类器和通用函数逼近器中这个单个隐藏层需要无数个神经元...
我们也看到了在通用布尔函数，通用分类器，通用逼近器中对于相同的逼近误差，更深的网络将需要少得多的神经元。
到并非可以一直用增加深度来减少宽度，这是有限制的！
仍然聚焦前面所讲过的这个例子：
![Pasted image 20261121194930.png\|254](/img/user/accessory/Pasted%20image%2020261121194930.png)
我们当时的做法是：在第一层使用16个神经元来表示是在这条线的左边or右边；在第二层使用40个神经元因为有40个黄色区域
如果在第一层只有8个神经元，但后面增加很多神经元，很多层，还能精确表示原图呢？答案是否定的。
![Pasted image 20261121205938.png\|215](/img/user/accessory/Pasted%20image%2020261121205938.png)
假设这8个神经元对应的是一个方向的8条平行线，我们后续第二层只能确定在哪个条带，而并不能确认在条带的哪个位置，对后续层实际恢复决策边界来说是不过的信息，即信息丢失了！
![Pasted image 20261121210032.png\|224](/img/user/accessory/Pasted%20image%2020261121210032.png)
即使这8个神经元表示的交叉的8条线 后续 只能得到一个大的网格 而并不能切出小的黄色区域
而第二层也不能少于40个！因为40个神经元是一块黄色区域对应一个检测器
这意味着，在每一层都有一个试图捕获决策边界函数所需要的最小神经元数量，深度智能继续加工传下来的信息，无法恢复已经被合并掉的、分类所必需的差异
阈值激活函数具有一种不好的特性：会限制信息！ 它只能告诉我们是在阈值的一侧还是另一侧，比如上面的例子中，如果第一层只有四个神经元只会得到在哪条条带中的信息，这对后续的处理边界是不够的。
怎么改变会使得更好？
我们希望激活函数不只是表明咋边界的一侧还是另一侧，我们希望激活函数能够继续提供信息表明距离边界多远
比如如果使用S函数，它不仅仅会告诉我们是在边界的左侧还是右侧，当远离边界时，值也会发生变化，这样我们可能会为构建边界的神经元提供了额外的信息
